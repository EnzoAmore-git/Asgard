# Приложение Асгард

Реализованы фаза 2 (вход и клубы) и фаза 3 (финансовая основа).

Запуск, локальный просмотр и настройки Telegram/VK: [PHASE2.md](PHASE2.md). Финансовые возможности, проверки и ограничения: [PHASE3.md](PHASE3.md).

Требования и архитектура находятся в корне проекта; карту чтения задает [AGENTS.md](../AGENTS.md). Реальные провайдеры отложены пользователем. Тренировки и пользовательские действия оплат/возвратов относятся к следующим фазам.

PHP 8.4, Laravel 13, MySQL 8.4, React, TypeScript, Vite. Зависимости закреплены в composer.lock и package-lock.json. Секреты, vendor, node_modules и собранные файлы не хранятся в Git. Развертывание PHP на GitHub Pages невозможно; Pages публикует только отдельный лендинг.
