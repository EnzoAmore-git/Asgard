# Приложение Асгард

Реализованы вход/клубы, финансовая основа, расписание, явка и абонементы.

Запуск — [PHASE2.md](PHASE2.md), финансовая основа — [PHASE3.md](PHASE3.md), текущие возможности и учебный клуб — [PHASE4.md](PHASE4.md).

Требования и архитектура находятся в корне проекта; карту чтения задает [AGENTS.md](../AGENTS.md). Решение об авторизации отложено. Оплаты, возвраты, исправления закрытой явки и доставка уведомлений относятся к следующим фазам.

PHP 8.4, Laravel 13, MySQL 8.4, React, TypeScript, Vite. Зависимости закреплены в composer.lock и package-lock.json. Секреты, vendor, node_modules и собранные файлы не хранятся в Git. Развертывание PHP на GitHub Pages невозможно; Pages публикует только отдельный лендинг.
