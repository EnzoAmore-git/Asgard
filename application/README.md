# Приложение Асгард

Фаза 2: вход, клубы, приглашения и совмещаемые права.

Запуск, локальный просмотр, проверки и настройки Telegram/VK: [PHASE2.md](PHASE2.md).

Требования и архитектура находятся в корне проекта; карту чтения задает [AGENTS.md](../AGENTS.md). Реальные провайдеры пока не настроены. Финансы и тренировки относятся к следующим фазам.

PHP 8.4, Laravel 13, MySQL 8.4, React, TypeScript, Vite. Зависимости закреплены в composer.lock и package-lock.json. Секреты, vendor, node_modules и собранные файлы не хранятся в Git. Развертывание PHP на GitHub Pages невозможно; Pages публикует только отдельный лендинг.
