# Лендинг Асгарда

Публичный адрес: https://enzoamore-git.github.io/Asgard/. Публикация через GitHub Actions настроена в `.github/workflows/pages.yml`: на Pages попадает только `landing/dist`, обновление происходит после изменения файлов сайта в ветке `main`.

Отдельная статическая страница до начала разработки приложения. Исходники для размещения — `dist/`: HTML, CSS, JavaScript и SVG. База, авторизация, аналитика, cookies и форма сбора данных не подключены. Кнопки ведут непосредственно на https://t.me/enzoamore и https://vk.ru/enz0amore; сайт не отправляет сообщения от имени посетителя.

Содержание опирается на PRODUCT_VISION.md, FUNCTIONAL_SPEC.md и утвержденную ARCHITECTURE.md. Приложение готовится к пилоту, иллюстрация интерфейса содержит вымышленные данные. Обещания цены, даты запуска и готовых интеграций не добавлять.

Текущий дизайн — v3: мобильный лендинг с северной морской темой, примером приложения на телефоне и простыми текстами. Перед изменением оформления или текстов читать [DESIGN.md](DESIGN.md). Мобильный просмотр без локального сервера — [mobile-preview.html](mobile-preview.html); каждый экран прокручивается отдельно. Предыдущие версии сохранены в asgard-landing-v1.zip и asgard-landing-v2.zip; актуальный комплект — asgard-landing.zip.

Локальная проверка: запустить статический HTTP-сервер с корнем `dist/`. Сборка и установка зависимостей не нужны. Для Beget достаточно содержимого `dist/` в публичном каталоге отдельного сайта; аккаунт Beget при создании лендинга не изменялся. `README.md`, `.openai/`, архивы и документы проекта публиковать вместе с `dist/` не нужно.

Проверять desktop и узкий экран, вкладки ролей мышью и клавиатурой, раскрытие FAQ, якоря, корректность контактов. Интерактивный пример объясняет возможности; это не реализация приложения.

Создана пустая приватная карточка Sites; идентификатор хранится в `.openai/hosting.json`. Загрузка исходников и публикация не выполнены: автоматическая проверка разрешений запросила явное согласие пользователя на передачу лендинга сервису Sites. Без такого согласия не повторять загрузку и не обходить ограничение другим инструментом. Приватная публикация сама по себе не заменяет общедоступное размещение на Beget.

Проверки v3: синтаксис JavaScript, уникальность ID, ссылки и локальные ресурсы; просмотр через iframe на ширинах 320/375/390/768/1440 px, без горизонтального переполнения; мобильный пример приложения и кнопки связи, роли мышью/клавиатурой и FAQ. Системное переключение reduced-motion отдельно не выполнялось; ограничение движения поддерживается CSS и JS. Реальные сообщения и заявки при проверке не отправлялись.
